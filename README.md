4. Что такое «короткое замыкание» в && и ||? Приведите свой пример, где это имеет практическое значение.
В A && B: если A уже false, то всё выражение false, и B не проверяется.
В A || B: если A уже true, то всё выражение true, и B не проверяется.
int divisor = 0;
int value = 10;
// Сначала проверяем, что делитель не 0 — и только потом делим.
// Если divisor == 0, правая часть не выполняется, и деление на ноль не происходит.
bool safe = (divisor != 0) && (value / divisor);
Console.WriteLine(safe); // False, программа не упала

6. Почему хорошим тоном считается расставлять скобки даже там, где они не обязательны по приоритету операций?
Потому что скобки делают порядок вычислений явным для человека, читающего код. Приоритеты операторов приходится помнить, а скобки «читаются» сразу и не оставляют двусмысленности.
